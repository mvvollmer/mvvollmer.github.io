      How it works

      The agents come from my CS 4180 paper with Dhananjai Senthil Kumar. In the original project the open-source poker environment we used had pot distribution bugs, which we flagged as a limitation. For this page I rebuilt the pipeline:

      • Rules-exact training. The agents were retrained in PokerKit, the University of Toronto's extensively tested poker library, which handles side pots, short all-ins, and split pots correctly.
      • A browser engine verified against it. The game you are playing is a JavaScript engine I wrote to follow PokerKit's rules, checked against PokerKit on 70,000 random hands (over 480,000 decisions) with zero disagreements.
      • The same agents, in your browser. The ReBeL agent's policy, value, and bet-sizing networks and the Q-learning table were exported from training and run here with no server; their outputs were checked against the Python originals.

      A different model for each table size

      A hand worth betting at a four-handed table can be a fold against five opponents. One network trained on every table size learned heads-up play well but played far too tight six-handed, so I fine-tuned a specialist for each table size and kept whichever model won more in a head-to-head test: the general model for two and three players, and specialists for four, five, and six. The page loads only the model for the table you pick.

      How the agents perform

      The ReBeL agent you play against, measured over 20,000 hands per table in the training environment, in big blinds won per 100 hands (95% confidence intervals). The field around it alternates Random and Q-learning bots:

      • Heads-up vs. Q-learning: +1,742 bb/100 (±105)
      • Heads-up vs. Random: +950 bb/100 (±62)
      • Three-handed: +1,417 bb/100 (±113)
      • Four-handed: +1,096 bb/100 (±103), up from +758 with the general model
      • Five-handed: +355 bb/100 (±68), up from +52
      • Six-handed: +199 bb/100 (±51), up from break-even (+1)

      For reference, the Q-learning agent beats Random heads-up by +1,000 bb/100 (±61).
