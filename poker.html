      How it works

      The agents come from my CS 4180 paper with Dhananjai Senthil Kumar. In the original project the open-source poker environment we used had pot distribution bugs, which we flagged as a limitation. For this page I rebuilt the pipeline:

      • Rules-exact training. The agents were retrained in PokerKit, the University of Toronto's extensively tested poker library, which handles side pots, short all-ins, and split pots correctly.
      • A browser engine verified against it. The game you are playing is a JavaScript engine I wrote to follow PokerKit's rules, checked against PokerKit on 70,000 random hands (over 480,000 decisions) with zero disagreements.
      • The same agents, in your browser. The ReBeL agent's policy, value, and bet-sizing networks and the Q-learning table were exported from training and run here with no server; their outputs were checked against the Python originals.

      Reading opponents

      The newest ReBeL agent knows who it is playing: each opponent is labeled Random, Q-learning, ReBeL, or unknown (which is how you appear), and it tracks their tendencies through the session, such as how often they fold to a bet and how aggressive they are. It also guesses what each opponent holds: every player starts each hand with all 1,326 possible hole-card pairs, and after every action those hands are re-weighted by how likely that type of player, with those tendencies, would be to take that action with each one. A raise from a tight player narrows them to strong hands; a raise from a Random bot tells it nothing. Its equity is then simulated against those estimated hands, not random ones. During training a share of opponents were shown as "unknown", so it learned to read players from how they bet alone.

      The best model for each table size

      A hand worth betting four-handed can be a fold against five opponents, so each table size uses whichever model won its head-to-head test. The tests use duplicate poker, the method tournaments use to remove luck: every deal is played twice with the two agents swapping seats, so both get exactly the same cards and only their decisions differ, across five independent runs of 3,000 deals (a control of the older agent against itself came out even at every table size).

      • Heads-up: the opponent-reading agent beat the previous agent by +1,120 bb/100 (±97), ahead in every run.
      • Three-handed: even (+19 ±119), so the table uses the opponent-reading agent for its reads.
      • Five-handed: an opponent-reading specialist beat the previous specialist by +123 bb/100 (±104), ahead in every run.
      • Four- and six-handed: the earlier specialists still win, so those tables keep them for now.

      How the agents perform

      Against a field alternating Random and Q-learning bots, over 20,000 hands per table, in big blinds won per 100 hands (95% confidence intervals):

      • Heads-up vs. Random: +1,030 bb/100 (±73)
      • Three-handed: +1,457 bb/100 (±122)
      • Four-handed: +1,093 bb/100 (±110)
      • Six-handed: +162 bb/100 (±50)

      With every opponent shown as "unknown", the opponent-reading agent still won +1,057 bb/100 heads-up and +1,158 three-handed, so it reads unlabeled players from their betting. For reference, Q-learning beats Random heads-up by +1,000 bb/100 (±61).
