# Sky catalogue data

Compact copies of the open catalogues from [d3-celestial](https://github.com/ofrohn/d3-celestial) v0.7.35
by Olaf Frohn (BSD 3-Clause; see `LICENSE-d3-celestial.txt`), trimmed for this site's sky map:

- `stars.json`: stars to magnitude 7, as `[RA hours, Dec degrees, magnitude, B-V colour index]`
- `messier.json`: the 110 Messier objects, as `[RA hours, Dec degrees, name, common name, type, magnitude, size A arcmin, size B arcmin]`
- `milkyway.json`: Milky Way outline in five brightness levels, each a list of rings of `[RA hours, Dec degrees]`
